# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming, whatever someone's experience level or background.
- Critique code and ideas, never people.
- No harassment, insults, or unwelcome attention in issues, PRs, or any project space.
- Assume good intent, and ask before assuming bad faith.

## Enforcement

Report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/KrishnaVaibhav). Reports are handled confidentially. Maintainers may
remove comments, close threads, or block contributors who violate this code.
